Gaussian Splatting for Unreal Engine — Import & Render PLY Splats

Unreal Engine has no built-in Gaussian Splatting support. This plugin was an early attempt to close that gap: bring a .ply splat capture into the editor and render it in-engine instead of as a mesh. It is a legacy implementation, and the page below says so plainly — if you are starting a splat project today, read the comparison before you buy.

Status note. Legacy implementation — last updated 2023. It still imports and renders splats, but the ecosystem has moved on and several free, better-maintained options now exist. Read the comparison before buying; if a free option fits your scene size, use it.

What it does

  • Imports .ply splat files as editor assets
  • Renders splats as a placeable actor you can move and frame
  • Useful for scans, exhibition content and previsualisation
  • Kept available for projects that already depend on it

Before you buy

Ask before buying if your scene is large or you need shadows. A refund is worse for both of us than an honest answer up front.
