How to read this site

Every plugin page starts with the gap in the engine, not the feature list. If the built-in option solves your problem, the page says so and you should use it. Plugins are listed by the name buyers search for, with the original name in brackets.

These are the questions that decide whether you need a plugin at all. Each answer is written to be useful on its own, including when the answer is “use the built-in feature”.

How do I open a second window in Unreal Engine?

Unreal renders one viewport per window. A second window needs a second GameViewportClient in C++ — here are the built-in options and what each one actually gives you.

How do I output Unreal Engine to multiple monitors?

Windowed mode, NVIDIA Surround, nDisplay or a runtime multi-window plugin. What each option actually does when you need Unreal on more than one display.

How do I use SQLite in Unreal Engine?

Unreal has no SQLite integration. Compare SaveGame, DataTable and a real SQLite plugin, and decide which one your project actually needs.

How do I make an HTTP request from Blueprint in Unreal Engine?

Blueprint has no HTTP node and FHttpModule is C++ only. Here is the C++ route, when a plugin is the better trade, and the pitfalls of both.

How do I encrypt a save game in Unreal Engine?

FAES exists in C++ but is not exposed to Blueprint. How to encrypt save data, where to keep the key, and why a shipped key is not secrecy.

Is there Gaussian Splatting support in Unreal Engine?

Unreal Engine 5.8 has no built-in 3D Gaussian Splatting renderer. Compare the three implementation approaches and the checks that decide whether a splat plugin survives production.

About

Nothing here changes the render pipeline in a way that breaks on engine upgrades.
